Self-registration

The master switch. When this is off, nobody can create their own account no matter which passcodes are set, and new staff can only be added from Users & Roles.

Passcode per role

Each role has its own code, so somebody handed the sales code can only ever create a sales account. Leave a box empty to keep the code that is already set — codes are stored scrambled and cannot be read back, so an empty box is normal.

How a passcode behaves

  • It is shared, so treat it like the shop keys: anyone who learns the administrator code can create an administrator.
  • At least {{ min_length }} characters.
  • Wrong codes are throttled — {{ max_attempts }} tries from one device, then a 15 minute wait.
  • Every attempt, right or wrong, is written to the audit log with the address it came from.
  • It cannot be read back. To hand it out again, set a new one.

What a new sales user gets

Someone registering with the sales code is asked who they report to. That choice is what gives them products to sell: they see their supervisor's stock, while their own sales, customers and debts stay theirs alone.

Everything else about them is the Sales role's defaults, which you can change under Roles — or per person under Access Control.
