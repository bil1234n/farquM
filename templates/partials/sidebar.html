{% load static core_extras %} {% comment %} Navigation, gated by permission. Hiding a link is a courtesy, not a control: every page here also checks the same permission in its own view, so typing the URL gets the same refusal. The point of hiding is that a sales assistant should not have to learn what they cannot do by walking into locked doors all day. Which link is lit is decided ONCE, by core.context_processors.nav_active, and arrives here as NAV. Do not go back to testing the view name inline: "production:material_list" contains the substring "product", so the tidy looking `{% templatetag openblock %} if 'product' in ... {% templatetag closeblock %}` lit up Products on every page in the yard.
